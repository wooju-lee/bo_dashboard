# Store Sales Analytics Report Dashboard

운영팀 요구사항 기반 매장 매출 분석 대시보드 프로토타입.

## 주요 영역

- **Filter Area** — Brand / Country / Channel / Store / Category / Period Type (DAY·WEEK·MONTH)
- **Goal Achievement & YoY** — 목표 달성률, 실매출, 판매수량, ATV, CVR
- **Action Insights** — Category WoW 하락, Sales Gap, Entry Traffic, Loss Risk, Reorder 알림
- **Sell-through Overview** — 전체 소진율 요약
- **Entry Traffic YoY** — 올해 vs 전년 입점객 비교
- **Product Top20 with Loss** — 상품별 판매량, Sell-through, 재고, Loss, YoY
- **Category Sell-through** — SUN / OPT / COL / ACC 카테고리별 소진율
- **SKU Sell-through Detail** — SKU 단위 상태 (Reorder / Watch / Stable / Slow)
- **Daily / Weekly / Monthly Summary** — 매장 담당자 운영 코멘트 입력 및 이력 조회

## 실행

브라우저에서 `index.html`을 열면 됩니다.
